# Seventeen Syllables of Debugging

A haiku about debugging, in strict 5-7-5 syllables:

> Cursor blinks at three
> the log scrolls red past midnight
> sleep was the error

Three in the morning, a blinking cursor, a log scrolling red past
midnight — and the twist: the real error was never in the code. It was
the debugger, running on no sleep.

## Run

```sh
node main.ts
```

Requires Node 22+. Standard library only, no network access. The program
prints exactly the three lines of the haiku to stdout.
